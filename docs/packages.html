4. 調査したが用いていないパッケージ

4.1 OpenCalphad（2026-10-25 調査）

Bo Sundman らによる無償の CALPHAD 計算ソフト（Fortran 95/08、GPL v3）。安定版 V6（OC6055、Windows インストーラ 2022-07-17）、開発版は GitHub で 6.138（2026-10-12）。conda-forge・PyPI には無く、gfortran + LAPACK/BLAS（同梱可）+ gnuplot でソースからビルドする（OpenMP オプション）。

区分機能
モデル（GTP）CEF（副格子 ≤ 9、分子・イオン・空孔）、部分イオン 2 副格子液体、秩序–不規則の分割（A1/L1₂/L1₀、A2/B2/B32/D0₃/L2₁）、Inden 磁性（修正版含む）、Einstein 温度、2 状態液体、体積・易動度・弾性定数などの性質パラメータ。MQMQA（修正準化学モデル）は 2025–26 の主開発対象で「fragile」、UNIQUAC は未完。
平衡（HMS）Hillert の算法、条件は組成・化学ポテンシャル・H・V・固定相・組成の式。グリッド最小化でミシビリティギャップ検出（fcc/bcc 秩序用・イオン結晶用の特別グリッド）。解析的 2 階微分 → Darken 安定行列・スピノーダル・Cp・拡散係数。OpenMP で複数平衡を並列。
図（SMP）STEP（性質図、相ごとの G 曲線）、MAP（二元相図・等温断面、タイライン）、不変反応からの出口、Scheil–Gulliver、パラ平衡 STEP、T0。出力は gnuplot と CSV（STEP のみ）。
アセスメントMINPACK LMDIF の最小二乗で実験・理論データ（平衡として入力）にパラメータを fit。不確かさ評価は着手段階。
データベースSGTE TDB 読み込み、FactSage 形式書き出し、XTDB（XML）は予備実装。高品質データベースは同梱しない。
インターフェースコマンドライン + マクロ、サードパーティ Windows GUI、OCASI（TQ 規格、iso-C binding、OCisoCbinding/pyOC に Python）。
作者が挙げる問題二元 MAP は「rudimentary」（線の欠落・準安定線、スタート点依存）、組成軸 STEP が二相域で停止、MAP 結果を保存できない、MQMQA は -O1 推奨。

本課題との関係：工程 05 → 06 は pycalphad と自前の凸包で済むので置き換える必然性はない。OC が優位なのは (1) LMDIF による TDB パラメータのアセスメント（calphy / QHA の G(x, T) 表を「実験平衡」として CEF に fit；pycalphad 側なら ESPEI が同等）、(2) Scheil・パラ平衡・T0、(3) MQMQA 液体、(4) OCASI による相場シミュレーションへの組込み。使うなら「05 で出した TDB（calphy の to_tdb）を OC の MAP で描き pycalphad と突き合わせる」検証用途が最も簡単。出典：opencalphad.com、news-oc7.pdf（2022-07-16）、GitHub（changes.txt）。

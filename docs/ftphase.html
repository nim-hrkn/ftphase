作成日：2026-10-21。相図計算 workflow ／ 実行済みの例と工程の対応 ／ 欠けている工程を補う公開ソース ／ 移行手順 ／ phase-diagram スキル（要約は references/ftphase.md）。パッケージ本体は ftphase/（README.md に導入と使い方）。

1. 何を作ったか

ftphase（version 0.1.0、MIT、src レイアウト、pytest 35 件）は、examples.html で「公開例に無い」とした工程を、public-sources.html で挙げた公開コードの上に実装したものです。1 行 = (相, 組成, T, P, G) の表 FreeEnergyTable を中心に、どの経路で得た自由エネルギーも同じ列（単位、基準状態、方法、配置項の有無、量子／古典、出典）に揃えてから凸包を取る設計にしました。

3. 実行結果

3.1 Al–Li EAM（workshop の 18 本の calphy 結果）：04A → 05 → 06 → 07

ftphase/examples/alli_eam_workshop.py → out_alli_eam/。6 組成 × 3 温度（800/900/1000 K）の同じデータを、B32 の配置項（全格子点理想混合＝チュートリアル／副格子反サイト＝workflow 第 4 節）と fit（3 次多項式／スプライン）で 2×2 に処理。組成は整数原子数の実組成（チュートリアルは公称組成。公称組成に戻すと 800 K の fcc+B32 が 0.193/0.255 となりチュートリアルの値を再現する）。

2 meV/atom の G 不確かさ（20 サンプル）で境界は x で ±0.02〜0.04、fit の形だけで共晶温度が約 85 K 動きます。fit 残差は poly3 で 2.5〜3.0 meV/atom。6 点の組成格子と 5 ps のスイッチングでは共晶温度は決まらないという結論自体が、workflow 第 8 節（境界付近の細分化、fit 誤差の評価）の要請を数値で示しています。B32 を副格子で扱うと、この EAM データでは 800 K で既に液相が安定で、共晶は 800 K 未満です。calphy 2.3 の PhaseDiagram に同じ表を渡した相図を calphy_phase_diagram_crosscheck.png に出力しました。

3.2 Al–Li ACE（実際の MLIP）：01、02A、03A、04B

ftphase/examples/alli_ace_validate_qha.py → out_alli_ace/。workshop の AlLi-6gen-18May.yace（Menon et al. 2024 の ACE）を LAMMPS pair_style pace で ASE から呼ぶ。CPU で約 10 秒。

  • 01：fcc Al E = −3.4789 eV/atom、V = 16.54 Å³/atom；bcc Li −1.7561；fcc Li −1.7556；B32 AlLi E_form = −0.179 eV/atom；L1₂ Al₃Li −0.094。緩和で空間群は保持。ACE では Al₃Li が凸包上（fcc–B32 の弦より 4.6 meV/atom 下）。照合表は Al₃Li を「MLIP ground state not in known list」と報告（Menon 2024 は Al₃Li を準安定としている。相図計算では候補に残し、結果に明記する）。pymatgen の e_above_hull との差は fcc-Li/bcc-Li のタイ処理による 0.55 meV 以内。Vinet：V₀ = 16.55 Å³、B₀ = 81.8 GPa（実験約 76）、B′ = 4.75。
  • 02A：32 原子ランダム Al₀.₈₇₅Li₀.₁₂₅（seed 0, 1）の未緩和 E = −3.2850 / −3.2847 eV/atom。icet の列挙 SQS（16 原子、cutoff 7.0/5.0 Å）はクラスターベクトル残差 0.203、E = −3.2879 eV/atom（sqs_Al0.875Li0.125.vasp）。
  • 03A：phonopy 2×2×2、9 体積（長さ −3 %〜+5 %）、Vinet。fcc Al：V(0 K) = 16.69、V(1000 K) = 18.13 Å³/atom、B(300 K) = 72.7 GPa、300–900 K の平均線膨張 32 ppm/K（実験 23–30、QHA と ACE の両方の誤差を含む）。B32 AlLi：V(0 K) = 16.36 → 17.51 Å³/atom、B(300 K) = 43.5 GPa。±3 % の走査では 1000 K の最小が範囲外になり例外で止まった（設計どおり）。
  • 04B：F_q − F_cl（調和）は fcc Al で 3.40 meV/atom（300 K）、1.03（1000 K）、B32 で 5.27 / 1.61 meV/atom。

3.3 ACE Al の融点：calphy TI（古典）と QHA（量子）の整合（03B → 04B → 05 → 06）

4. 実装中に見つかった落とし穴（修正済み）

  • phonopy の固定メッシュ [4,4,4] は primitive_matrix='auto' で基本胞が小さい純元素・規則相では q 点 64 個しかなく、1500 K の F が 18 meV/atom ずれた（例 7）。メッシュは長さ（密度）で指定する（mesh=60.0）。
  • phonopy を primitive_matrix='auto' で使うと振動数は基本胞あたり。入力セル（立方胞）あたりに換算しないと F_vib が 4 倍小さくなり、量子補正も 0.85 meV/atom と出た（正しくは 3.4）。回帰テスト test_phonopy_free_energy_is_per_input_cell。
  • 凸包で同じ x に複数相の点があると、単調鎖がより高い点を残すことがある。同じ x は最も低い相だけを残す。
  • QHA の走査範囲：Al は 1000 K で体積が +9 % を超える。±3 %（長さ）では最小が範囲外。例外で止めて走査を広げる（外挿しない）。
  • 3 次多項式を G そのものに当てると x ln x の端点の形を再現できず、標本ノイズから偽の二相域（fcc+fcc、liquid+liquid）が出る（例 5）。PhaseCurve.from_points(ideal_T=T) で理想混合項を解析的に分離して過剰項だけをフィットする。builder_from_table は config_entropy が ideal / liquid-ti の相に自動で適用（正則溶体の解析解で検証）。
  • 3 次多項式 fit は端点（B32 の x = 0.5）で 46 meV/atom ずれることがある（副格子項を入れた B32 系列）。fit_residuals で確認し、スプラインか組成点の追加で対処。
  • calphy の gather_results(extract_phase_prefix=True) は本パッケージの folder_prefix 形式から相名を取り出せない。読み込み側でフォルダ名の先頭から補う。
  • GPU で ACE（2026-10-22、GPU 復旧後、結果は 3.4）：conda-forge の LAMMPS 22 Jul 2025（KOKKOS/CUDA ビルド）には pace/kk はあるが hybrid/scaled/kk が無い。calphy は固相 Frenkel–Ladd の fe 以外のすべて（reversible scaling、液相 UFM、alchemy、dcci）で pair_style hybrid/scaled を使うので、-k on を付けると "Must use pair_style hybrid/scaled/kk with Kokkos" で止まる。また pace/kk は pace product しか受け付けない。対処：env/lammps-gpu/build.sh で LAMMPS stable 30 Sep 2026（hybrid/scaled/kk あり）を KOKKOS/CUDA sm_86 + ML-PACE でビルドし、calculation_block(gpu=True, lammps_executable=…) が md.cmdargs・pace product・queue.cores=1・--gres=gpu:1 を書き、gpu_capability で走らせられないモードを入力生成時に拒否する。
  • calphy 2.3.0 の CLI 既定では融解・凝固検出が無効（tolerance.solid_fraction = 0、liquid_fraction = 1）。pyiron 経由では有効だったため examples.md の記述を訂正。calculation_block は既定で 0.7 / 0.05 を書く。

5. 未実装・制限

  • 二元系のみ。三元以上は calphy to_tdb → pycalphad の経路（check_with_pycalphad は簡易比較のみ）。
  • AiiDA 版は失敗セルだけの再投入（再開）とキャッシュを使っていない。失敗セルは除外して組み立て、直したら WorkChain を再投入する。
  • CE+MC は ftphase.ce（icet 列挙・学習、mchammer SGC / VCSGC、固溶限抽出）で接続（3.9）。限界は CE の精度と振動項の欠落。smol・状態密度 → F_conf の受け口は別。
  • 04B の補正は調和近似で、液相側の量子効果は扱わない。
  • 誤差伝播は相ごとの一様オフセット（＋任意の傾き）。組成依存の誤差は未対応。
  • sqs_sqsgenerator は未テスト（icet 経路を使う）。

2026-10-21 に 実行済みの例で埋まらなかった工程（01、02A の SQS・副格子、03A の phonon/QHA 本線、04A の副格子配置項と CE+MC、04B、05 の TDB 化、06 の line phase を含む多相凸包、07 の誤差感度）について、公開されているソースコードで補えるかを調べた結果です。各ツールの記述は公式文書・論文・GitHub の表示を同日に確認したもので、本ホストで動かして検証したのは「導入済み」と書いたものだけです。

1. 結論

  • 欠けている工程はすべて公開コードで補えます。ただし一つの統合パッケージは無く、工程ごとに別のコードを組み合わせます。
  • 導入済みの calphy 2.3.0 の calphy.phase_diagram.PhaseDiagram クラスが 05・06 の大半をすでに持っています。G(x,T) を GHSER + 理想混合 + Redlich–Kister に分解し（build_calphad_surface）、line compound と限定組成相を含む TDB を書き出し（to_tdb）、pycalphad / OpenCalphad で読めます。upstream の examples/ と docs/ に入力例は無く、2026-05〜07 の commit（d72f25d, 90a93e3）で入った機能です。examples.html と examples.md の旧記述「二元限定・line phase 非対応」は誤りで、同日に訂正しました。
  • 主軸は「icet（02A/04A）＋ aiida-alamode と phonopy（03A）＋ calphy PhaseDiagram（03B/05/06）＋ pycalphad（06/07）」。参照実装として exaPD（Ames/LANL）と Menon 2024 の pyiron ワークフローを読みます。
  • 自作が避けられないのは、(a) QHA 由来の G(T,V,x) と calphy TI 由来の G(T,P,x) を同じ表形式・同じ基準に揃える変換層（04B/05）、(b) SQS 系列 → aiida-alamode → calphy PhaseDiagram を結ぶドライバ、(c) 境界の誤差感度（07）の 3 点です。

5. 推奨する組み合わせ

  1. 01：matcalc を env/pyiron に追加し、EOS・弾性・phonon のベンチマークと 0 K 凸包（pymatgen）を回す。融点は calphy の melting_temperature。
  2. 02A：icet を env/pyiron に追加し、副格子・空孔を含む SQS を generate_sqs_by_enumeration（小セル）または generate_sqs（大セル）で生成。セル形状・原子数・cutoff・目標相関との差を記録する（workflow.md 第 2 節）。
  3. 03A：SQS ごとに aiida-alamode で体積走査の調和 phonon → thermo の F(T) を集め、phonopy の QHA 関数で式 (D2)。補助経路は calphy の固相 TI。
  4. 04A：第一近似は式 (E2)/(E10) の理想混合・副格子項。規則相の組成幅や短範囲秩序が効く系では icet の CE を MLIP で学習し、Wang–Landau または TI で F_conf。
  5. 03B/05/06：液相は calphy の UFM TI。全相を calphy PhaseDiagram の DataFrame に揃え、calculate(calphad_surface=True) で境界、to_tdb で TDB。QHA 由来の固相はここへ流し込む変換層を書く。
  6. 06/07：TDB を pycalphad で再計算し、calphy の境界と一致するか確認。三元以上は pycalphad の Mapping。誤差は calphy の error を伝播させるか ESPEI の MCMC。

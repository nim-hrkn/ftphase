2. 補間関数を使わない経路（B 系）での可否と計算量

「補間関数を使わない」こと自体は MLIP を選ばない。差が出るのは、手法が pair style に課す条件（fix sgcmc だけ EAM 専用の高速経路）と、MC の試行ごとに全エネルギーを計算する分の計算量である。

手法使える MLIP条件・計算量
半大正準 MC（fix atom/swap + MD）すべて試行ごとに全系のエネルギーを前後 2 回計算（fix atom/swap の文書）。コストは「試行数 × 全エネルギー 1 回」。EAM の Ag–Cu（2,048 原子、Δμ 36 点 × 3 温度、各点 20 + 20 ps）は 8 ランクで 25 分/等温線。ACE・GRACE-FS は 1 回のエネルギーが EAM の 50〜100 倍重く、GPU で 2,048 原子 0.05 s/回（grace/fs/kk の実測 2.6 s / 50 ステップ）として同じ試行数なら 1 点 1〜2 時間、1 系 100〜200 GPU 時間。試行数と Δμ 点数を絞れば日単位。GPU + pace/kk の組合せは未検証。
分散拘束 SGC（fix sgcmc、VCSGC、Sadigh 2012）高速な実装は EAM のみ（eam/alloy、eam/fs）LAMMPS の文書どおり、他の pair style では「全エネルギー再計算・直列 1 プロセス」の汎用経路に落ちるので実質不可。VCSGC が要るなら CE 上の mchammer（ftphase.ce.vcsgc_scan）で代替。
二相共存 MD（界面法）すべて、GPU 可通常の MD だけ。EAM の例（agcu_sgcmc/coexist.py、6,144 原子 × 400 ps）を ACE で GPU なら 1 本 15〜20 時間、2,048 原子なら数時間。融点・液相線向き。
Gibbs–Duhem 積分すべて共存する 2 相の MD から ΔH・Δx を取って dμ/dT = −ΔS/Δx を積分。自作が要る。
CE + MC（icet、SGC / VCSGC、ftphase.ce）学習エネルギーの計算に ASE で呼べるものすべて（LAMMPSlib 経由の上記全部、MatterSim・SevenNet、tensorpotential）MC は CE 上で走るので MLIP の重さは学習だけ（Ag–Cu の 631 構造で 3 分）。CE の打ち切り誤差（Ag–Cu で 9 meV/atom）と振動項の欠落が残る（docs/ftphase.html 3.9）。
calphy TI + 離散凸包（A-1、関数なし）第 1 節の全部、GPU は ACE・GRACE・SNAP現行経路（05 の表 → 06 の凸包）から補間関数を外すだけ。B 系ではないが補間なし。
MLIP で B 系を回す順序：(1) 共存 MD で融点・液相線（GPU、ACE / GRACE-FS）。(2) 固溶限は fix atom/swap を GPU で試行数を減らして回すか、短距離秩序が本質の系では CE+MC。固溶限の温度依存に振動が効く系（Ag–Cu 型）では MD 込みの fix atom/swap が必要で、CE+MC では出ない。最初の一歩は Al–Li の ACE で fix atom/swap + pace/kk を 1 点（800 K、Δμ 1 つ）流して所要時間を測ること。

3. float32 と float64（2026-10-24 測定、env/lammps-gpu-grace/test/prec/）

MACE・SevenNet の既定 float32 が TI の精度（1 meV/atom）に足りるかを測った。結論：足りる。float32 の丸めは 1 評価あたり 0.1〜0.2 µeV/atom で、TI の統計誤差（0.1〜1 meV/atom）より 3 桁小さい。

SevenNet の有限差分（h = 0.01 Å）の力誤差 2.5 meV/Å は、1 評価あたりのエネルギー丸め 0.05 meV（256 原子の総和）/0.02 Å に相当し、解析力の誤差ではない。SevenNet の float64 実行は sevenn 0.12 の checkpoint 互換パッチと fx 定数が float32 固定で失敗した。GRACE の fp32 版は径方向 MLP だけを cuBLAS fp32 にする設計で、総和は倍精度。

結論：calphy の TI（サーモスタット付き）では float32 で問題ない。float64 が要るのは長い NVE と、エネルギー差 1e-5 eV 級を直接使う構造最適化・フォノン有限差分（03A の変位 0.01 Å では SevenNet の有限差分力誤差 2.5 meV/Å が効くので float64 か変位 0.03 Å 以上）。

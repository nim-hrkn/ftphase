4.1 potentials-workshop-2022 tutorial_2（Al–Li、workshop の EAM）— 実計算で再現

pyiron-examples/workshop2022-phase-diagram/。18 本の Calphy ジョブ（純 Al の fcc／液相／B32 格子、xLi = 0.1–0.5 の fcc・液相・B32、800–1000 K の reversible scaling、5000+5000 ステップ）を実行し、analyze_phase_diagram.py で解析。これが 02A → 03 → 04A → 05 → 06 → 07 を一通り通した唯一の例です。

工程tutorial_2 での実装workflow の要求との差
01無し。ポテンシャルは与えられたものを使う純元素融点や既知境界での検証は行っていない
02Afcc の Al をランダムに Li へ置換、B32 の Li をランダムに Al へ置換（整数原子数の実組成）SQS ではなく単一のランダム配置。B32 を x=0 まで外挿する系列は物理的な相ではない
02B固相と同じセルを calphy の溶融サイクルで液化溶融・平衡化の判定は calphy 内部に任せている
03A（補助）/ 03Bpyiron の Calphy ジョブ（library mode）で固相は Einstein 結晶、液相は UFM を参照に TIphonon/QHA は使わない。振動と非調和は TI に含まれる
04Afcc と B32 に理想混合項 −T·Sconf（式 (E2)）を加算。液相には加えないB32 に全格子点の理想混合式を適用しており、workflow.md 第 4 節が戒める近似。副格子ごとの占有率は使っていない
05全相 eV/atom、同じ EAM、液相端点を結ぶ直線を差し引いて共通基準化単一ポテンシャル内なので参照状態の問題は生じない
063 次多項式フィット + fsolve の共通接線（チュートリアル）、3 相の下側凸包（本プロジェクトで追加）線形相・限定組成相の扱いは無し
07T–x 図を 5 K 刻みで作図、二相域を tsv に保存誤差評価は無し（1 反復、error = 0）

結果：共晶 ≈ 863 K、xLi ≈ 0.22。その下に fcc+B32 二相域 x = 0.19–0.25、上に fcc+液相と B32+液相。実験の共晶は約 870 K、xLi ≈ 0.26。純 Al の fcc／液相交点は 900–1000 K（実験 933 K）。

calphy 2.3.0 では B32 格子上の純 Al（融解）と x=0.4 の液相（凝固）が MeltedError / SolidifiedError で中断します。workshop 当時の calphy 1.0.3 にこのチェックは無く、チュートリアルはこの準安定状態の値をフィットの端点として使っています。再現のため該当 2 本だけ tolerance.solid_fraction = 0、liquid_fraction = 1 で再実行しました。

4.2 Menon ほか 2024（Al–Li、EAM）の公開データセット — 後処理のみ

pyiron-examples/menon2024-alli-eam/。edmond の公開アーカイブ（Calphy ジョブ 84 本）を pyiron HEAD で unpack し、calphy 2.3.0 の phase_diagram モジュール（get_phase_free_energy → get_free_energy_mixing → get_common_tangents → plot_phase_diagram）で相図化。対応工程は 04A（理想混合、B32 は entropy_correction=0.5）、05–07。この EAM では 700 K でも xLi > 0.16 で液相が fcc より低く、fcc+液相の二相域が下まで続きます。生の自由エネルギーで確認済みで後処理の誤りではなく、01 の「ポテンシャルを検証してから相図へ進む」の必要性を示す例です。

7. 今回分かった落とし穴

  • calphy の --validate は dry run ではなくジョブを投入する。パースだけなら calphy.input.read_inputfile(path, validate=True)。
  • calphy は <mode>-conf.data-…data をカレントディレクトリに書く。並列ジョブは作業ディレクトリを分ける。
  • 同じ条件の入力はフォルダ名が衝突する。folder_prefix で区別する。
  • calphy 2 系は融解・凝固を検出して中断する（tolerance.solid_fraction / liquid_fraction で無効化可）。準安定端点が必要な設計では意図して無効化し、記録する。
  • calphy 2.1.x は pyscal3 < 4、2.2 以降は pyscal3 ≥ 4。conda-forge は 2.1.2 止まり。
  • pyiron の unpack は現行版では archive/{export.csv, <project path>} の配置と sqlite DB を要求する。
  • calphy 2.3.0 の plot_phase_diagram は tangent_types と phases を要求し、get_phase_free_energy はデータ外を値 1.0 で埋める。凸包はそのまま取れるが、境界 x=0, 0.5 で幅ゼロの偽セグメントが出る。
  • 相図の T–x 図を fill_betweenx で一括描画すると温度ごとに不連続な領域が線で結ばれる。温度ごとに帯を描く。
  • GPU で calphy（ACE）を回す場合（2026-10-22、ftphase 3.4）：注意点：GPU 1 枚ではジョブが直列になるため、総スループットは CPU 8 コアと同程度です。利点は 1 本の待ち時間短縮と、CPU を QHA に空けられることです。
